## Comentarios editoriales

`⌥ + C` (Mac) / `Alt + C` (Windows) activa el modo comentario. Los comentarios se
registran en el Google Sheet vía Apps Script (`WEB_REVIEW_CONFIG.webhookUrl` en
`v1/index.html`, `projectName: gobernanza-v1`).

Uso interno. No indexado.
